# 정승의 푸끼몬 챔피언스 LAN v5.4 Reconnect Sprite Scale

1세대 최종진화체 + 피카츄 안정판입니다.

## 핵심

- 1세대 중 최종진화체 + 피카츄만 후보로 사용
- 터미널에 필요한 상태만 표시
- `게임 실행 가능` 문구 출력
- 새 게임 요청 버튼 제거, 항복 버튼으로 변경
- 항복 시 상대 즉시 승리
- 플레이어 접속/팀 선택/행동 선택 로그 표시
- 후보 12마리 화면이 위쪽에 명확히 표시
- 2마리 선택 후 LAN 배틀
- 상태이상, 파괴광선 반동, 채팅 유지

## 실행

```bash
npm install
npm start
```

정상 준비가 끝나면 터미널에 아래 문구가 표시됩니다.

```text
게임 실행 가능
서버 주소: http://localhost:3000
친구 접속: http://내IPv4주소:3000
```

## 문법 검사

```bash
npm run check
```
