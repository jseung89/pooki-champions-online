- 무료 Render 인스턴스는 일정 시간 접속이 없으면 잠들 수 있습니다.
- 첫 접속은 30초~1분 정도 지연될 수 있습니다.
- 서버 메모리 랭킹은 서버 재시작 시 초기화될 수 있습니다.
- 영구 랭킹은 추후 Supabase 같은 외부 DB 연결이 필요합니다.
